# رابط — النسخة المتصلة

هذه النسخة تحوّل ملف الواجهة إلى مشروع React/Vite قابل للتشغيل، وتضيف:

- Tailwind CSS فعلياً.
- نقطة تشغيل `src/main.jsx`.
- API لحفظ الحالة.
- SQLite محلياً للتطوير.
- Supabase اختيارياً للإنتاج.
- استيراد ملفات `xlsx/xls/csv/txt`.
- باركود CODE128 وQR حقيقيان.
- إنشاء فاتورة عند استلام/تسليم الطلب.
- مزامنة مؤجلة مع الخادم وتخزين محلي احتياطي.

## التشغيل المحلي

```bash
npm install
npm run dev:server   # API على 4000
npm run dev          # الواجهة على 5173
```

افتح: `http://localhost:5173`

أو شغّل النسخة المجمّعة في خدمة واحدة:

```bash
npm run build
npm start            # الواجهة وAPI على 4000
```

## ربط Supabase

1. أنشئ مشروعاً في Supabase.
2. افتح SQL Editor وشغّل `supabase/schema.sql`.
3. انسخ `.env.example` إلى `.env`.
4. ضع `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` في الخادم فقط.
5. شغّل `npm start`.

لا تضع `SUPABASE_SERVICE_ROLE_KEY` داخل متغير يبدأ بـ `VITE_` ولا داخل الواجهة.

## النشر المجاني

ملف `render.yaml` مجهز للنشر على خدمة Node مجانية، مع Supabase كقاعدة بيانات خارجية. من لوحة الاستضافة أضف:

- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`

لا يمكن تنفيذ خطوة النشر النهائية من دون حساب الاستضافة ومفاتيح مشروع قاعدة البيانات الخاصة بالمالك.

## ملاحظات مهمة قبل الإنتاج

الواجهة الأصلية ما زالت تستخدم حسابات العرض التجريبية والأدوار الموجودة في `DEMO`. يلزم استبدالها بتسجيل دخول حقيقي وصلاحيات من الخادم، ثم فصل حالة كل شركة/مستخدم بدلاً من حفظ حالة منصة واحدة في سجل واحد.
